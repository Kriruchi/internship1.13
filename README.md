# Sales Data Analysis Dashboard

## Overview
This project analyzes sales transaction data using Power BI to understand revenue, profit, and regional performance.

## Dataset Used
- Source: Excel File (Company Sales Data)
- Total Columns: 9 (Date, Client, Contact, Department, Region, Payment, Revenue, Profit, Profit Margin)
- Date Range: 30-05-2023 to 02-06-2023

## Data Cleaning Process
The raw data was cleaned in Excel / Power Query before visualization:

1.  Setting Column Size: Fixed ##### errors by using AutoFit Column Width for Date, Revenue, and Profit Margin columns.
2.  Setting Row Size: Removed duplicate rows (e.g., Costco, McDonald's entries were repeated) to fix the total row count.
3.  Handling Missing Values: Replaced NA values in Payment and Revenue columns with null for accurate.
